One Emoji, One Smile — this entry sends a single emoji, the Sun with Face 🌞, the one most likely to make a stranger smile. `main.py` writes exactly that emoji to `/output/entry.txt`: warm at first glance, universal, and chosen rather than the default smiley face. Ten candidate emojis were compared against the judge's warmth criteria before this one was picked.

## Run it

```sh
python3 main.py
```
